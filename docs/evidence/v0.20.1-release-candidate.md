## Scope

This corrective release contains no feature expansion. It:

- bumps the application and vendored workspace identity from `0.20.0` to
  `0.20.1`;
- fixes the Tauri updater signer invocation on current CLI versions
  (`--password=` instead of the literal password `""`);
- makes the isolated update rehearsal restore an absent registry baseline
  correctly and allows a pre-release candidate to be supplied as local files;
- adds deterministic hostile-outcome coverage to the production updater
  decision path: origin/mirror success, empty bytes, corrupt/truncated
  signature failures, timeout, stale manifest, all-source failure ledger,
  forged higher-version refusal, and same-version source priority;
- adds an explicit `-NsisOnly` local validation mode while retaining MSI+NSIS
  as the default release build. `-NsisOnly` is not MSI release evidence.
