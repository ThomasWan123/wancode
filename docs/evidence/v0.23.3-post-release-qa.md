## 6. 缺陷与更新办法

### BUG-01 — P1 — 空会话找不到「显示」菜单（重度使用者）

**现象：** 新开会话或清掉消息后，首页是空态，`Messages` 整段 `display:none`，View 按钮一起消失。升级前这三个选项在输入框旁，发第一条之前就能改。现在只能 Ctrl+K 循环，重度使用者会以为功能被拿掉了。

**复现：** 空闲 + `items.length === 0` → 无 `View:` 按钮。  
**证据：** `hides the View control on an idle empty transcript`。  
**现有发布测试抓不到：** `Messages.view.test.tsx` 都带着样例消息挂载。

**更新办法（推荐，改动面小）：** 空态不要把整段消息区藏死，只收起列表、留下工具条。

```tsx
// src/features/messages/Messages.tsx
<section
  className={`messages${items.length === 0 && !busy ? " messages-empty" : ""}`}
>
```

```css
/* src/App.css */
.messages-empty {
  flex: 0 0 auto;
  overflow: visible;
  padding: 8px 10% 0;
  min-height: 0;
}
```

同时：`items.length === 0 && !busy` 时 `setViewMenuOpen(false)`，避免 BUG-05。

**验收：** 空会话仍能看见「显示: 标准」；切到精简后再发第一条，工具细节被藏住。新增测试：空 `items` 仍能 `getByRole('button', { name: /View:/ })`。

**反向路径：** 有消息时工具条保持 sticky；空态首页（`.empty-state`）仍居中，不被 `flex:1` 的消息区挤掉。

---

### BUG-02 — P2（发布卫生）— 仓库 `latest.json` 停在 0.19.0（项目经理）

**现象：** clone tag `v0.23.3` 的人会在根目录看到 updater 还是 0.19.0。线上 Release 资产是对的。

**更新办法（三选一，推荐 A）：**

A. **仓库不再跟踪发布快照。** 删除根目录 `latest.json`，在 `scripts/release.ps1` / README 写明「只从 Release 资产或 `Write-WanCodeUpdateManifests` 生成」。  
B. **发布提交同步生成。** 发版时用同一生成器覆盖仓库文件，使 `latest.json.version === package.json.version`。  
C. **CI 合同。** `versions` job 增加：若文件存在，则 `version` 必须等于 `package.json`，且 URL 文件名含该版本；否则红。

**验收：** 审计员打开仓库不再看到 0.19.0；`versions` 对「过期入库 manifest」会红。  
**反向路径：** 不要改 `tauri.conf.json` 里已工作的 `releases/latest/download/latest.json` 端点。

### BUG-03 — P2 — 打开菜单焦点总在「精简」，不是当前档（重度使用者）

**现象：** 当前是标准或调试，键盘打开菜单，焦点在第一项「精简」。再按一次 Enter 会误切到精简（Enter 本身是好的，起点错了）。

**证据：** `opens the menu with focus on the first option, not the checked option`。现有测试 `Messages.view.test.tsx` 还把「焦点在 Minimal」写成了正确行为，修的时候要改掉这条断言。

**更新办法：**

```ts
useEffect(() => {
  if (!viewMenuOpen) return;
  const selected = viewMenuRef.current?.querySelector<HTMLButtonElement>(
    "[role='menuitemradio'][aria-checked='true']",
  );
  (selected ?? viewMenuRef.current?.querySelector<HTMLButtonElement>("[role='menuitemradio']"))
    ?.focus();
}, [viewMenuOpen]);
```

**验收：** 当前调试 → 打开菜单 → 焦点在「调试」且 `aria-checked="true"`。  
**反向路径：** 尚无选中项时仍聚焦第一项。

---

### BUG-04 — P2 — 清会话后菜单状态残留（重度使用者）

**现象：** 有消息时打开 View 菜单，Ctrl+K 新会话（`setItems([])`），消息区被藏起但 `viewMenuOpen` 仍为 true。下一条消息到来时菜单已经开着。

**证据：** `reopens a leftover View menu after the transcript is cleared then restored`。  
**代码：** `App.tsx` 新会话只清 `items`；`Messages.tsx` 不监听空列表。

**更新办法：**

```ts
useEffect(() => {
  if (items.length === 0 && !busy) setViewMenuOpen(false);
}, [items.length, busy]);
```

点 backdrop / Escape / 选中一项后关闭的路径保持不变。

---

### BUG-05 — P2 — 会话尚未建立时，三层共用一句「描述一个任务或提问…」

**现象：** `sessionId` 为空时 `Composer` 走 `t.composerHint`，Chat/Code/Work 看起来一样。自动开会话很快时窗口短；手动开文件夹或启动失败时，重度使用者会觉得三层没分开。

**证据：** `falls back to the generic hint on %s before a session exists`。  
**有会话后是对的。**

**更新办法：** 把表面选择提到 `sessionId` 之前（busy / starting 仍优先）：

```tsx
placeholder={
  busy ? t.queueHint
  : starting ? t.starting
  : surface === "chat" ? t.composerPlaceholderChat
  : surface === "work" ? t.composerPlaceholderWork
  : t.composerPlaceholderCode
}
```

**验收：** `sessionId=""` 时 Chat/Code/Work 各用自己的句子。  
**反向路径：** 忙碌中仍显示排队提示；启动中仍显示 starting。

---

### BUG-06 — P2 — Chat / Work 首页建议仍是代码任务

**现象：** `buildSuggestions` 只看 git dirty / README / tests，不看 `surface`。Chat 和工作层首页会出现「审查未提交的改动」「跑测试」。和 v0.23.3「三层语言要分开」的设计打架。

**更新办法：** `buildSuggestions(files, git, t, surface)`：

- Chat：总结 / 提问 / 解释，不推 commit/test。  
- Work：问资料 / 引用文档，不推 git commit。  
- Code：保持现有 dirty/README/tests 逻辑。

`Home` / `App` 传入 `surface`。补三条单测。

---

### BUG-07 — P2 — 应用内 updater 仍是单 GitHub 端点

**现象：** Release 已发双 manifest，但 `tauri.conf.json` 只有：

`https://github.com/ThomasWan123/wancode/releases/latest/download/latest.json`

国内 GitHub 资产失败时，应用内更新不会自动改走 `latest-gh-proxy.json`。这是 v0.20 A3 已写明、尚未做完的客户端编排，不是 0.23.3 新引入的，但 0.23.3 已经把镜像资产发上去了。

**更新办法：** 按 `docs/design/v0.20-a3-multi-mirror-updater.md` 做逐源 `check()` + 同版本不降级下载；**不要**只把镜像 URL 塞进 `endpoints` 数组就当容灾（插件会吃第一个能解析的 manifest，没有字节级回退）。

**验收：** GitHub 资产 404/超时时，同版本镜像下载成功且验签通过。  
**反向路径：** 镜像版本低于 origin 时不得安装降级包。
