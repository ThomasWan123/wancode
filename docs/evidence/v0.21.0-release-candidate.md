# v0.21.0 release candidate evidence

Status date: 2026-08-24

Candidate base: `main@95dd06a02a97e23752eee931ca1494444d2877e6`

## Scope

This release packages the auditable harness-kernel foundation merged in PR #75:

- append-only execution ledger with fail-closed integrity diagnostics;
- immutable capability leases and lease-bound Job/Terminal ownership;
- single-use approval receipts bound to live session and advertised options;
- production provider-profile wiring and request/usage evidence validation;
- bounded rolling reads with global mutation barriers;
- deterministic concurrency, cancellation, document-containment and plugin
  fan-out regression coverage.

Cowork orchestration, scanned-document OCR, and non-native provider tool
presentation remain gated and are not release claims.

## Known boundary

Authenticode signing is not currently available. The MSI and NSIS executable
will therefore remain Authenticode unsigned unless an independent signing
credential is supplied before publication. The Tauri updater signature is a
separate mandatory control and may not be waived.

Any item still marked `PENDING` or `NOT-RUN` is not evidence of success.
