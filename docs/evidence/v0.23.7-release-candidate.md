## Authenticode decision and limitation

The user's recorded 2026-08-11 decision deferred Authenticode for personal use.
Reconsider signing before external promotion, expansion to external user groups,
store distribution, or use in environments requiring strict EDR trust.
The RC runs with `require_authenticode=false`; this does not verify a trusted
Windows publisher. Unsigned installers can produce Windows trust warnings or
be blocked by enterprise policy. This is an explicit limitation, not an omitted
test. Final publication authorization must explicitly address this limitation.

Tauri updater signatures are a separate integrity mechanism, not Authenticode.
Their validity against the final installer and equality between both manifests
and the uploaded signature asset must be verified during publication.
