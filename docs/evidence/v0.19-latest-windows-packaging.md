## Decision impact

The NSIS package is functionally installable, launchable, and removable under
the tested Windows 11 user context. Distribution remains **NO-GO** because the
artifacts are unsigned, the latest MSI cannot be produced, and clean-machine,
upgrade, rollback, and signed-publisher matrices remain incomplete.

An isolated forced-crash setup attempt at `0b86c77` initialized WebView2 but
did not enter the AUTOTEST path or create a controlled dirty session. A
separate normal-context launch of the exact release binary did expose the
recovery banner and restore the exact durable session identity, so the
release-binary slice is a partial pass. The installed-package, controlled
rich-history, and failure-retry slices remain open; see
[`v0.19-packaged-crash-recovery-attempt.md`](v0.19-packaged-crash-recovery-attempt.md).
