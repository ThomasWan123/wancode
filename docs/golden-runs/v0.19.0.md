## 3. Confirmed defects and findings

| ID | Severity | Summary | Reproduction | Required action |
|---|---|---|---|---|
| QA-019-001 | P1 | `snapshot_writes_patch_for_dirty_tree` is not hermetic and writes snapshots under the process-wide real `GROK_HOME` | Test failed with access denied in both the system temp root and a workspace `TEMP`; passed only after setting an isolated `GROK_HOME` | Give the test an isolated user-data root before `grok_home()` is initialized; assert the real user root is unchanged |
| QA-019-002 | P1 | The current CI Rust command can race on identical `wancode_lib` cdylib/staticlib outputs on Windows | Exact combined command emitted output filename collisions and failed with `LNK1104`; `--lib -j 1` completed independently | Split library and integration targets into separate commands or otherwise guarantee unique artifacts; add a Windows regression check |
| QA-019-003 | P2 | Frontend production bundle is large and has a mixed static/dynamic import | Vite reported an 824.63 KB main JS chunk and duplicate import mode for the opener plugin | Add a bundle budget, inspect manual chunks, and make import strategy consistent |
| QA-019-004 | P2 | Pinned engine dependencies emit future-incompatible and unused-code warnings | Four implicit `f64` to `f32` fallback warnings plus several unused imports/assignments | Track in the engine maintenance backlog before the next Rust toolchain upgrade |
| QA-019-005 | P2, CLOSED | Public README described React 18 while `package.json` uses React 19.1.0 | Static documentation/package comparison | README corrected to React 19 in the quality-plan branch |
